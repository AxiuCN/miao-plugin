Fork面板变换：换 / 补
构建“虚拟面板”，不修改已获取的真实数据，伤害数字旁显示变化差异（绿色↑ / 红色↓）。换（局部替换）与补（重设基础）是两种不同操作：
换 — 基于面板替换部件（武器 / 圣遗物 / 命座 / 天赋 / 角色 / 属性数值），结果与原存档面板对比：
#胡桃面板 换少女头　换装
#胡桃面板 换+30暴击　属性数值变换，必须带“换/变/改/补”关键字触发（如 #胡桃面板 变-10%大攻击）
#胡桃面板 换+30暴击换-10%大攻击　多属性变换，各属性之间用“换”分隔（百分比仅对攻/生/防按基础值计算）
#雷神面板 换90级6命天赋91212 胡桃　换角色/命座/天赋
#雷神面板 换精五稻光　换武器　#雷神圣遗物换赛诺圣遗物　换圣遗物
#心海伤害 138638352 换芭芭拉花+毛+沙+杯　跨UID圣遗物
补 — 重设面板基础（角色 / 等级 / 命座 / 天赋 / 武器），作为虚拟面板的基准，可与换叠加，伤害差异以补出的基础为基准对比：
#雷神面板 补90级满命天赋101313 换精五雾切
